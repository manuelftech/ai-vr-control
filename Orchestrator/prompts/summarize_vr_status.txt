*Summary Prompt*
Create a summary of the object's state, including:
- Tag elements (separated by dots)
- Movement status (rotating or levitating)
- Color (if applicable)

*Rules:*
- If `ConstantForce.Force.Y` ≥ 9.83, it's levitating. Otherwise, it's on the ground.
- If `RelativeTorque` ≥ 4.76, it's rotating. Otherwise, it's not rotating.
- If `Color` is present and ≠ #000000, describe the color in normal words.

Example output: "Tag1.Tag2... is [rotating/levitating] and is [color]."
