The virtual environment is controlled via an integrated, command-based interface. Users interact with a chatbot powered by ChatGPT—a powerful language model—to issue requests using a virtual keyboard.
This system facilitates extensive environmental modifications, including altering object colors (e.g., furniture, props) and manipulating physics properties (e.g., levitation). The system is capable of executing multiple concurrent item modifications efficiently. The underlying operations rely on specific algorithms integrated within the Unity Engine platform.
Important Operational Note: As the environment does not impose vertical limits, objects set to levitate will continue moving indefinitely until they are no longer visible. Users should manage levitation commands accordingly.
